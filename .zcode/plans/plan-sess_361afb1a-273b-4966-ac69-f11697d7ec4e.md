# MADS Implementation Plan — Proton X70 on Kommu KA2

## Summary of findings

**MADS standby steering is feasible on KA2**, but requires app-firmware changes (recoverable) in addition to Python changes. The signing keys were deleted from the repo but are recoverable from git history (commit `70b17dd8`), and the device's bootstub accepts debug-signed firmware. The bootstub itself must never be touched (no DFU recovery on KA2 = permanent brick).

**Why MADS worked on KA1 but not KA2:** KA1's firmware set `controls_allowed = true` unconditionally. KA2's firmware ties it to stock ACC state via `pcm_cruise_check`. When openpilot is enabled but the firmware reports `controlsAllowed = false`, the `controlsMismatch` check in selfdrived.py disengages after ~100ms.
